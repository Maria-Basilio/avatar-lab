## ✦ About the Project

**Avatar Lab** is an interactive web application inspired by retro pixel art games, designed to let users create and customize their own pixel-style characters.

The project combines a nostalgic visual experience with interactive frontend features, allowing users to experiment with different character elements, save their creations, and build a personal avatar collection.

More than just an avatar creator, Avatar Lab is an exploration of creativity, frontend development, and interactive web experiences.

## ♡ Features

- **Avatar Customization:** Create unique pixel characters by combining different visual elements.
- **Character Collection:** Save customized avatars and access previously created characters.
- **Avatar Export:** Export your creations.
- **Interactive Experience:** Navigate through an intuitive interface and customize characters in real time.
- **Retro Pixel Art Design:** A visual identity inspired by classic games and pixel aesthetics.
- **Local Data Persistence:** Keep saved creations using browser Local Storage.

## ✦ Getting Started

You can run Avatar Lab locally by following these steps.

### 1. Clone the repository

```bash
git clone https://github.com/Maria-Basilio/avatar-lab.git
```

### 2. Open the project folder

```bash
cd avatar-lab
```

### 3. Run the application

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for a local development environment.

No additional installation is required.
